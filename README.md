# Системы мира: Птолемей, Коперник, Тихо Браге, Кеплер

3D-симулятор движения Солнца, Луны и пяти планет в четырёх исторических системах. Модели работают одновременно
и стоят рядом. Под каждой можно включить вид неба с поверхности Земли (или из центра Солнца).

## Запуск

Приложение — статические файлы без сборки. Three.js подключается из CDN jsdelivr.

* **GitHub Pages:** положите содержимое папки `sim/` в репозиторий (в корень или в `docs/`) и включите Pages.
  Все пути относительные, поэтому работает и из подпапки.
* **Локально** нужен любой HTTP-сервер (ES-модули не грузятся по `file://`), например:

  ```bash
  node tools/serve.mjs 8765
  ```

  Затем откройте http://localhost:8765/.

## Управление

* **Модели** — 1–4 панели, они стоят рядом по горизонтали.
* **Время.** Шаг симуляции — сколько модельного времени проходит за один шаг. Скорость — шагов в секунду.
  Есть кнопки ⏮/⏭ (один шаг), ⇄ (обратный ход), ввод даты и памятные даты.
  Даты до 15.10.1582 — по юлианскому календарю, годы астрономические (0 = 1 г. до н. э.).
* **Камера** центрируется на Земле или Солнце. Поворачивается только мышью: вращение самого тела на камеру не влияет.
  Колесо — масштаб, двойной щелчок — сброс.
* **Отображение:**
  * деференты, эпициклы, экванты, линии построения;
  * следы — относительно центра камеры. Например, следы в системе Коперника при центре «Земля» рисуют петли — эпициклы Птолемея;
  * звёздная сфера (≈ 5000 звёзд ярче 6ᵐ из каталога Yale BSC), плоскость эклиптики, небесный экватор;
  * суточное вращение: у Птолемея и Тихо вокруг Земли вращается вся небесная машина, у Коперника и Кеплера — сама Земля.
* **Небо с поверхности.** Место наблюдения у каждой модели своё: Александрия, Фромборк, Ураниборг, Прага. Можно задать общее.
  Есть горизонт, эклиптика и экватор, следы планет на фоне звёзд (видны попятные петли).

## Модели

| | Источник | Механизм |
|---|---|---|
| **Птолемей** | «Альмагест» (≈150), «Гипотезы о планетах» | Эксцентр + **эквант** + эпицикл. Кривошип Меркурия, лунный деферент с точкой просневсиса. Широты по кн. XIII. Расстояния — вложенные сферы (Сатурн до 19 865 R⊕, звёзды 20 000 R⊕). |
| **Коперник** | De revolutionibus (1543) | Центр — центр земной орбиты. Эксцентр + **эпициклет** (d : r = 3 : 1) вместо экванта. Колеблющиеся наклоны орбит, двойной эпицикл Луны, трепидация прецессии. |
| **Тихо Браге** | 1588; таблицы Лонгомонтана (1622) | Солнце и Луна вокруг Земли, планеты вокруг Солнца. Вариация Луны, колебание наклона лунной орбиты и узлов. |
| **Кеплер** | «Новая астрономия» (1609), «Рудольфинские таблицы» (1627) | Эллипсы с Солнцем в фокусе, уравнение Кеплера. Элементы a, e, i — рудольфинские. |

**Исторические числа.** Средние движения, радиксы и все параметры Птолемея взяты из «Альмагеста».
Эксцентриситеты, эпициклеты, расстояния и наклоны Коперника; солнечные и лунные параметры Тихо; a, e, i Кеплера.

**Реконструкция** (точных таблиц под рукой нет):
* средние долготы планет на эпоху автора (1525 / 1590 / 1627), рассчитанные по современным средним элементам;
* узлы и перигелии Тихо и Кеплера;
* эксцентриситет Венеры у Коперника;
* средние аргументы Луны у Коперника, Тихо и Кеплера.

Каждая модель считает от своей эпохи своими средними движениями. Поэтому накопленная ошибка Птолемея видна честно:
к XVII веку Солнце и планеты у него уходят на 5–8°.

## Проверка

```bash
node tools/check.mjs
```

Скрипт печатает отклонения геоцентрических долгот и широт каждой модели от современной эфемериды на ряд дат.
Около своих эпох:

| Модель | Отклонение |
|---|---|
| Птолемей (137 г.) | ≲ 4° |
| Коперник и Тихо | ≲ 1° |
| Кеплер | ≲ 0,3° |
| Луна во всех моделях | ≲ 1° |

Каталог звёзд пересобирается так: `node tools/build-stars.mjs stars.6.json`. Исходный файл —
[d3-celestial](https://github.com/ofrohn/d3-celestial), производный от Yale Bright Star Catalogue.
